# 初芽 · 新教师成长站 MVP V0.1

面向入职三年内中小学教师的工具与资源导航。使用 Next.js App Router、TypeScript、Tailwind CSS 和本地 JSON，无登录、数据库或外部 AI 调用。

产品迭代记录、需求与原因、验证证据、风险及后续反馈流程见 [初芽产品迭代与验证日志](CHANGELOG.md)。后续每轮按“明确指标 → 开发与技术验证 → 负责人体验 → 提问与反馈确认 → 记录 → 讨论下一步”维护；未确认的体验不标记通过。

## 本地启动

需要 Node.js 22+ 和 npm。当前环境已使用 Node.js 24 验证。

```bash
cd /workspace/Teacher-Compass
npm ci --cache /workspace/.npm-cache
npm run dev
```

开发服务默认使用 3000 端口。在自己的电脑上可用浏览器打开 http://localhost:3000；云端请使用平台支持的端口访问方式。本任务界面不提供 localhost 预览链接。

```bash
npm test          # 核心推荐逻辑测试
npm run typecheck # TypeScript 检查
npm run build     # 生产构建
npm start         # 构建后启动生产服务
```

## 文件说明

- `app/page.tsx`：首页及四个任务示例、四个场景入口。
- `app/recommend/page.tsx`：需求展示、条件识别、最多三个候选资源。
- `app/tools/page.tsx`、`components/Library.tsx`：关键词、学段与类别筛选。
- `app/tools/[id]/page.tsx`：工具详情、官方入口、限制及操作步骤。
- `components/TaskForm.tsx`：输入校验及推荐页面跳转。
- `components/ToolCard.tsx`：资源卡片及可展开指南。
- `data/tools.json`：32 条资源，修改这里即可维护工具库。
- `lib/recommend.ts`：规则匹配与未来 AI 的接口，独立于页面。
- `lib/scenarios.ts`：自然表达别名及学生受伤情境识别与安全提示。
- `tests/recommend.test.ts`：推荐排序、空结果、输入限制、目录完整性及安全情境测试。
- `app/globals.css`：响应式样式。

## 推荐规则与局限

每个匹配标签加 3 分，完整类别名称匹配加 4 分，按得分降序取前三个；同分按初始数据顺序，明确包含“简单”时优先入门工具。通过“小学/初中/高中”识别学段。当前学段数据为广泛候选覆盖，未经逐一验证，不能视为适用性认证。

费用资料全部标记待核验；不会承诺满足免费约束。难度为编辑初步判断，并非官方评级。未使用模型、不保存用户需求、不上传学生信息。操作指南为入门探索建议，具体产品界面和功能待核验。未添加虚构评价。

## 下一步接入 Dify 或 LLM

1. 在服务端新增推荐 API，实现 `RecommendationProvider`，保留规则实现作为降级路径。
2. 通过服务端环境变量管理密钥，不使用 `NEXT_PUBLIC_`，不写入 JSON 或 Git。
3. 模型只返回本地目录中存在的工具 ID；服务端验证结构和 ID，再读取真实链接和资料。
4. 加入超时、错误提示、调用限额与隐私告知；测试推荐相关性与不编造信息。

本版本无需 API Key，不会产生 AI 服务费用。接入前先核实工具数据及价格，取得调用服务所需账号和授权。

## 情境推荐更新

支持“学生不愿发言”“不交作业”“设计一节课”等显式别名，每个别名命中类别加 4 分。

“我的学生在课堂上受伤了”等表达优先触发安全提示，仅推荐教育部、中国政府网作为事后政策查询入口，不把普通工具作为救助方法。安全课、演练等准备性表达会显示准备提示。提示不是医疗诊断，无法识别所有危险情况；关键词规则仍有误判和遗漏。20 项逻辑测试覆盖这些分支。

## EduToolbox 清单参考扩充（2026-10-20）

目录由 12 条扩充到 32 条，覆盖 10 个本地任务分类；分类面向本项目，并非复刻原站分类。
依据用户在聊天中提供的清单节选，未成功直接读取原站，不确认原站总数量及免费、免登录、本地处理等概况。
现有国家中小学智慧教育平台、学科网、Canva、希沃白板合并来源，不重复创建。其余新增 20 条，候选入口均待独立核验。

新增课件、题库与班级工具：101教育PPT、AiPPT、菁优网、21世纪教育网、雨课堂、希沃班级优化大师、ClassIsland、优品PPT、第1PPT。
新增辅助、成长与科研资源：Notion、Wolfram Alpha、Quizlet、BoardMix、中国大学MOOC、学堂在线、中国国家数字图书馆、国家哲学社会科学文献中心。
新增多媒体工具：OBS Studio、腾讯会议、Zoom。

`data/tools.json` 中 `sources` 记录参考来源、来源类型和整理日期，整理日期不是验证日期。所有条目的费用、学段和难度都不是已认证结论。
公开课直播、青教赛视频、声波球等同名或通用条目缺少唯一入口，未收录。也未将清单中未给出具体内容的工具补齐为“247 条”。后续应逐项访问真实产品及文档，核查身份、功能、费用、许可与隐私政策。

## 学生冲突场景

“学生之间发生肢体冲突”“学生打架”“同学推搡”等表达会展示现场安全和呼叫支援提示，并保留政策查询入口。准备防冲突班会时展示安全教育准备提示；已明确发生受伤或打架时优先展示处置提示。规则不认定欺凌或责任，不替代学校流程、校医及警方。

## 校园常见情境（28 类）

`data/school-scenarios.json` 保存 26 类常见情境、触发短语、建议步骤、补充问题和关联资源；`lib/school-scenarios.ts` 负责情境匹配。另有 `lib/scenarios.ts` 中的受伤与肢体冲突两类优先提示，共 28 类。推荐页可以展开浏览并点击示例。

覆盖课堂纪律、注意力、课堂参与、作业、学习差异、考试诚信、备课、公开课、言语冲突、同伴排斥、考试焦虑、情绪激动、融合教育、家长投诉、家校联系、考勤、校外活动、设备故障、隐私、版权、教师压力、教学研究、去向不明、自伤风险、疑似侵害、身体不适，以及受伤与肢体冲突。

安全事项优先于普通情境；同类按命中短语的具体程度选择一个主情境。受伤及冲突仍会保留独立安全提示。不是完整的多意图理解，也不保证识别所有自然表达。未匹配时保留真实空结果，不随机给出工具。

建议为一般性编辑参考，未逐条核验政策依据，不构成医疗、心理或法律诊断，也不代替学校流程。高风险事项优先寻求现场专业支持。资源仅辅助后续记录、教学或政策检索，官网入口不等同于具体事件处理文件。当前 24 项测试覆盖原有推荐、全部 26 个示例、冲突及安全优先级和误触发检查。
