# V0.2 技术验收与负责人体验卡

日期：2026-10-21（北京时间）。分支：`feat/issue-1-mvp-v02`；对应 [Issue #1](https://github.com/ivyhuang3560-tech/Teacher-Compass/issues/1)，审阅入口 [PR #2](https://github.com/ivyhuang3560-tech/Teacher-Compass/pull/2)。

## 开发前明确的验收口径

1. 首页、教育动态、发展活动、工具导航可访问，四个主导航一致且选中正确。
2. 六个教育专题支持多标签；信息类型、地区与关键词筛选有响应，新闻不显示法律效力。
3. 活动支持类别、地区、学段、学科、状态筛选；演示/未核验记录不能进入开放报名，空结果可恢复。
4. 32 条工具原记录和 28 类情境规则保留，安全事项优先。
5. 全站及栏目自然语言入口明示规则/DEMO，输入过长、空结果和不存在页面均有提示。
6. 筛选可写入 URL，详情返回保留条件；移动端不出现横向溢出，键盘可跳到主内容。
7. `npm test`、`npm run typecheck`、`npm run build` 通过，并完成浏览器检查与截图。

这些标准来自 Issue，不是满意度或教学效果指标。负责人体验尚未确认。

## 技术结果

- 35 项逻辑测试通过，含原有 24 项回归和新增 11 项内容、来源、分类、筛选、日期状态与边界测试。
- TypeScript 检查及生产构建通过。
- 浏览器使用 Chromium，桌面 1440px、移动端 390px。检查四主页面、筛选、详情返回、报名空结果、活动需求匹配、32 条工具、全局安全优先、错误/404、移动端无横向溢出、键盘跳过导航；最终 9 组浏览器检查通过，页面脚本错误 0 个。
- HTTP 补充检查：46 个详情页均成功，三个不存在的详情路由返回 404。
- 本轮仅修改 package 版本号为 0.2.0，未增加 npm 依赖。

## 数据事实核验与未完成

教育部和中国政府网原始请求被代理返回 403；无法核实原始文章。本轮 8 条教育动态、6 条活动全部是 DEMO，无真实发文、通知、主办方、日期及报名。演示条件不是现实信息。真实内容、工具外部入口与收费仍需独立核验；未进行教育/法律/医疗专业审查。

活动日期状态的“报名中/已结束”等自动测试使用独立、明确命名的测试夹具，夹具不在产品数据中，也不表示已有真实报名服务。
