# 初芽：全国信息来源与免费接入可行性评估

调研日期：2026-10-21（北京时间）。本文件是产品调研与技术预评估，不是已上线的接入能力。

## 已确认的产品约束

负责人明确选择：**全国权威来源优先；免费优先，付费另行确认。** 本轮不创建账号、不申请 API Key、不购买、不部署、不实现采集任务，也不扩大为地方站点接入。

用户原始反馈：“由于各类信息都是demo呈现，我没办法较好评估具体政策、法律和活动与检索的对应情况。”据此建议先验证真实内容的相关性，而不是直接把模型或自动化当作解决方案。反馈归纳及整轮产品验收仍待负责人确认。

## 结论与证据边界

建议首批候选：**教育部 → 国家法律法规数据库 → 中国教育学会**；中国政府网作为政策交叉核对和补充；中国教育科学研究院作为教研活动补充。国家中小学智慧教育平台先保留资源导航，不作为开放资讯 API 使用。

以上是基于机构职能与初芽需求的产品优先级判断，不是实测接入成功的排名。教育来源在本次环境均被代理返回 `CONNECT tunnel failed: 403 Forbidden`，不能将其解释为源站拒绝采集、没有 API/RSS或站点不可用。原文、robots、使用条款、RSS/API、页面结构及抓取许可尚不能核实。**目前没有教育来源被确认为“已验证可自动接入”。**

另一方面，Cloudflare 和 GitHub 的官方文档仓库可以读取，本文件的部分部署/定时费用结论有实际文档依据；其费用不代表已购买或可无条件免费运行本项目。

| P0 | [国家法律法规数据库](https://flk.npc.gov.cn/) | 高；教育相关法律原文、版本与法律效力核对，比普通资讯站适合作法律来源 | 小规模法律目录及原文导航；修订、施行和废止状态人工复核 | 自动检索、动态页面/API和授权待核验；不通过发布日期推断现行有效，不先批量镜像全文 |

| P1（交叉核对） | [中国政府网](https://www.gov.cn/) | 高；国家层面教育政策及权威解读，活动相关性较低 | 用于补充与核对，不与教育部重复抓取成两条资源 | 政策原文和解读必须区分；原文 URL、栏目及自动获取方式待核验 |
| P2（教研补充） | [中国教育科学研究院](https://www.nies.edu.cn/) | 中高；教育科研、成果、学术交流信息，与普通新教师的适用范围需筛选 | 有明确教师对象和可核验原文时少量补充 | 不能把所有科研项目都当作新教师可申报；机构通知资格、正文和接入规则待核验 |
| P2（资源导航） | [国家中小学智慧教育平台](https://basic.smartedu.cn/) | 高资源相关性；课程资源和教师学习，但不是天然的资讯聚合接口 | 先保留原有工具库入口；具体公开资源人工核对链接 | 不假设有公开免费 API，不采集需登录资源，不承诺课程可下载或计培训学分 |
| 备选 | [教育部教育技术与资源发展中心相关候选入口](https://www.ncet.edu.cn/) | 拟核对数字教育与教师信息素养相关活动 | 身份、入口与面向对象核对后再考虑 | 此次仅作候选，当前访问受阻；不把候选域名身份或具体赛事说成已核实 |

本轮不优先接入：泛教育自媒体和聚合转载、付费搜索或商业法律库、来源不明的活动报名页、仅有公众号名称却无可核对原文的通知。它们可以成为线索，但不作首批事实依据。

## 内容更新频率：建议值，不是源站承诺

| 内容 | 完成许可和技术核验后的建议频率 | 未能自动获取时的低成本替代 | 展示要求 |
| --- | --- | --- | --- |
| 教育部政策及通知 | 每天一次，建议北京时间 09:17 左右 | 每周两次人工检查重点栏目 | 分开发文日期、抓取成功时间与人工核验时间，不称实时 |
| 教育法律目录 | 每周一次检查修订、施行与废止线索，重大变更人工加查 | 每周人工核对精选法律；被检索时提示核验日期 | 效力状态不能由脚本只按时间猜测；不确定保留待核验 |
| 教师活动 | 每天一次；只有选中来源可靠且确有时效需求时，再考虑每天两次 | 每周两次人工核对通知；临近截止重点复核 | 报名条件、日期、取消/延期和费用以原通知为准；不确定不标报名中 |
| 中国政府网补充 | 每天一次或与教育部任务合并 | 录入重要政策时人工交叉核对 | 同一文件合并，不把转载当新政策 |
| 科研活动补充 | 每周两次足够作为起步假设 | 人工筛选 | 不承诺每次都有适合新教师的活动 |
| 工具及资源链接 | 每月一次复核；费用与高频工具可按需求加查 | 优先人工核对用户实际使用的工具 | 可访问不等于功能、授权、价格和学段全部核验 |

为什么不做秒级实时：初芽当前任务需要准确来源与可理解的条件，而非高频刷新。低频更新减少请求、维护与误报，先看真实用户是否需要更快。频率是后续可调整的产品假设，不是性能承诺。

## “可链接”与“可同步”要分开验收

1. **原文链接导航**：确认域名和具体文章，记录来源、标题及日期，写自己的简短摘要并链接原文；不复制整篇内容。仍需核对使用条款和引用方式。
2. **RSS / 官方开放 API**：优先考虑，但本次没有发现并验证教育来源的可用官方接口。需要先核对公开文档、许可、限额与字段，不使用未公开登录接口或别人的凭据。
3. **允许的公开页面解析**：仅在适用条款、访问规范和技术可行性确认后考虑。robots 不是完整授权；可浏览也不等于可任意采集或转载。不绕过登录、验证码、反爬、TLS/签名校验。
4. **人工录入降级**：若禁止自动获取或接口不稳定，保留原文导航及人工复核，不编造自动更新能力。

每个来源的接入门槛：具体栏目与三条原文可重复访问；能抽取标题、来源、日期及正文事实；能识别更新与重复；已评估条款/robots及引用范围；超时/403/页面变化会停用或告警，不覆盖最后一次有效内容；同来源原始样本由人工复核。通过前不标记自动可接入。

## 免费方案与部署决策

### 现在建议

- **不购买服务，不租云服务器，不申请付费搜索或 LLM API，不购买域名。** 保留本地 demo，先核验一批真实内容。全国来源优先，活动宁缺毋滥。
- 有了真实数据并确需手机或他人访问，再选择一个可运行现有 Next.js 的免费托管入口。任何账号登录、密钥绑定与公开部署都先另行确认。
- 同步任务和网页托管是两个独立部分。网站能访问不意味着数据会更新；GitHub 数据更新也不意味着本地 Windows 副本自动变化。
- 当前 Next.js 使用服务端搜索和 URL 筛选，**不能直接把现有项目原封不动上传 GitHub Pages 或纯静态 Pages 就承诺完整运行**。必须选择兼容运行时，或另外改造静态检索，不能为省部署费用暗中削减功能。

### 已取得官方证据的候选

| 项目 | 官方文档中可确认的事项 | 对初芽的判断 |
| --- | --- | --- |
| GitHub Actions | 官方文档说明公开仓库的标准托管 runner 使用免费；私有仓库有按套餐的额度与超额计费 | 可候选用于低频内容同步，前提是仓库/runner类型、平台规则及来源许可适用；不是网页托管。避免长时间保留大附件，设置适当预算/停用规则；不以免费为理由公开隐私 |
| Actions 定时 | 默认按 UTC；工作流在默认分支运行；繁忙时可延迟甚至丢弃；公开仓库 60 天无活动会停用定时工作流 | 不保证准点/持续运行。本分支未合并前不能声称定时任务会自动运行；无须立即创建任何 workflow |
| Cloudflare Workers | 官方文档仓库说明 Free 计划有限额；示例文档额度为每天 100,000 请求、HTTP CPU 10ms；Paid 最低 $5/月并存在超额计费 | 可做免费小规模验证，但请求额度不能证明本项目 SSR CPU/兼容性合格。付费最低价不是本项目费用报价，也不代表获准开通 |
| Cloudflare Pages | 官方文档仓库列 Free 每月 500 次构建；完整 Next.js 与静态导出部署路径不同 | 不可将静态托管额度套用于当前完整 SSR。Cloudflare 当前 Next.js 文档涉及适配路径且以 Next.js 16 为例，当前项目 15.5.x 的兼容性须试验，不为部署而自动迁移框架 |
| Vercel | [Hobby 官方说明候选入口](https://vercel.com/docs/plans/hobby) 当前直接读取被代理阻挡，未独立核验现行条款与费用 | 与 Next.js 的部署方式可作为优先评估候选；在核对免费、非商业/其他使用限制、配额、超额与国内访问前，不作免费可部署保证 |

官方文档仓库是本次实际可读取的证据；线上套餐可能更新且因账户而异。最终以注册、部署当日的官方页面与账户设置为准。以 0 元新增服务费为目标，不承诺永远零成本；人工核验与维护时间也是成本。

### 推荐分阶段路线

**阶段 A：真实内容验证（先做，尚未立项实施）**

- 选教育部、法律库和一个全国活动来源，先核验约 8—12 条法律/政策及少量实际活动通知。数量是目标，不够则如实空缺。
- 法律候选检索主题可从教师法、义务教育法、未成年人保护法、家庭教育促进法开始；政策候选可查教育惩戒、教师职业行为和课程标准。这里只是拟核验清单，不认定版本、现行效力或已找到原文。
- 活动可使用明确标注已结束的真实历史案例来检验相关性，但绝不当作当前可报名机会。
- 先测试“问题 → 具体原文”的对应关系；若检索不相关，先改分类与规则，而不是先增加抓取频率或模型成本。

**阶段 B：免费同步试验（需阶段 A 结果及负责人确认）**

- 若来源确实允许自动获取，先单一来源、每日一次、只增量抓取；不一次接入十几个站。
- 可考虑 GitHub Actions → 待审内容文件/内容 PR → 人工复核 → 发布。不要直接把机器抓来的内容自动标为已核验。
- 项目现用 JSON 打包随构建读取，更新 JSON 后需要对应代码/数据同步和重新构建部署；它不是现成的运行时实时数据库。

**阶段 C：共享体验部署（另行确认）**

- 优先验证现有 Next.js 无额外付费的托管兼容性与国内访问表现，使用平台子域名即可。
- 免费不可满足时，报告具体原因、替代方案和可核验报价，负责人明确批准后才能付费。没有自动接受收费、绑卡或升级。
- 公开发布前处理已登记的依赖风险、日志隐私与来源使用问题。

## 建议的验证指标（待负责人确认后执行）

| 维度 | 起步验收口径 |
| --- | --- |
| 原文可追溯 | 每条真实内容都有具体原文 URL、机构与核验日期；不得用机构首页假装文章来源 |
| 内容身份 | 法律/政策/资讯分类清楚；活动有真实对象与适用条件；不伪造报名中 |
| 检索相关性 | 负责人给 5 个真实问题，逐条判断结果是否能回答；小样本只逐项记录，不宣传总体准确率 |
| 法律与活动时效 | 选中法律核对版本/效力；活动截止、取消或延期与原文一致，未知则保留待核验 |
| 同步可靠性 | 试运行至少 7 天，记录每次成功/失败及原文变更；失败保留旧内容并显示最近成功同步时间，不承诺实时 |
| 费用与许可 | 已确认来源获取方式、平台账号/免费额度和开支设置；未经单独批准不发生收费 |

计划中的时间字段应区分 `publishedAt`、`retrievedAt`、`verifiedAt`、`lastSuccessfulSyncAt`。自动抓取不是人工核验，拿到 URL 不是验证相关性；本轮不修改现有模型或实现这些字段。
